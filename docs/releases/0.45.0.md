# 0.45.0: the AI Lab chat, rebuilt like ChatGPT

## Answers drawn as reports

- The AI now writes its answers with blocks the chat draws itself: tiles for the key numbers,
  real tables (numbers at the end, gains green and losses red), tinted boxes for a tip, a
  warning or a stop, small line, bar and donut charts, numbered next steps and meters for how
  much of a limit is used.
- The AI decides which block fits where. It is told to use them only when they make the
  answer clearer and to take every number from the app's own data.
- A chart card of the app's own data (stats, R distribution, Monte Carlo, trades) now stands
  where the AI put it in the answer, not only under it.

## The chat

- Copy under every answer (the whole answer), on every table and code block, and on your own
  message (on hover).
- Retry asks the same question again.
- Your message sits at the end of the line in a soft bubble; the composer is round and grows
  with your text; a round button jumps to the latest message.

## To test

Ask "How did my trades do this month?" and "What is wrong with my settings?". The answers
should show tiles, a table or a warning box only where they help. Click Copy and paste it in
a note. Scroll up and use the round button to come back.

An answer saved before 0.45.0 opens as before: plain Markdown is still drawn as text.
