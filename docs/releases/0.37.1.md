# 0.37.1

AI Lab polish after the first look at 0.37.0.

- Short requests like "معاملات اخیر رو نشون بده" or "show my recent trades" now draw the real card straight away, without asking the AI. The AI is told to always use cards and never repeat the data as a Markdown table.
- Chat text uses the bundled Vazirmatn font. Numbers and code keep IBM Plex Mono.
- The user bubble is rounded and fits its text.
- One working line per answer ("Working... · step"), instead of two lines at once.
- The quick prompts are one sliding row with arrows, shown only on the welcome screen.
- Right column lists (History, Saved prompts) wrap long titles instead of overlapping, and the Usage panel no longer cuts off its right side.
