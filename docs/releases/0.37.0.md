# 0.37.0

- New look, step 5 of the No Curve v2 design (docs/NOCURVE_V2.md): the AI Lab is drawn
  like the design, Persian and right to left, with real data only.
- At the top PAPER ONLY and REAL ORDERS: NEVER, then the four steps of the loop (export,
  check, compare, activate); a step turns green only when it is really done.
- The chat (760 px) and the inspector side by side:
  - Settings: the export scope, the optional Ask AI connection (off by default) and the
    comparison symbol and dates;
  - History: saved chats, open one or start a new one;
  - Prompts: saved prompts, use one or save the message box;
  - Files: the exports, Export for AI and Copy prompt;
  - Experiments: every checked suggestion, its result and whether it was turned on;
  - Usage: tokens and cost per request, with the daily cap.
- The manual loop runs as cards inside the chat: paste the AI's JSON into the message box
  and it is checked on this PC (no AI call), then Run comparison, the verdict with its three
  rules, and Activate in Paper after the four checks (or Ignore).
- Chart cards from the app's own data: stats, equity now and with the suggestion (same
  period), R distribution, Monte Carlo, trades, candles with entries, the parameter
  sensitivity map and the walk-forward windows. The agent can draw up to 3 per answer; the
  quick prompts draw them directly.
- The account number is never sent to the AI.
- Nothing on this page sends a real order.
