# 0.46.0: edit a question

The changes are in docs/releases/0.45.1.md (release-please counts a feature as a minor
version):

- Hover your message in the AI Lab chat: **Edit** puts it back in the message box, so you can
  change a word and send it again. Copy is next to it.
- In an empty message box the up arrow brings back your last question.
- The answers, the cards and the saved chats work as in 0.45.0.
