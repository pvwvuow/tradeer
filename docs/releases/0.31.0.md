# 0.31.0: Workstation UI v2, the look (19a)

The first phase of the owner's UI v2 design (docs/UI_V2.md).

- New ink and cream theme: a green-black page with cream text (light theme: cream paper
  with ink text). The current page, the primary button and checked buttons are drawn
  inverted. Green, coral and amber only for results and warnings. Every color pair passes
  WCAG AA.
- Flat: no gradients, smaller corners (8 / 6 / 4 px), underlined tabs, outlined status
  chips and badges.
- Numbers, captions, table headers and the status bar in a monospaced face: IBM Plex Mono
  where installed, else Cascadia Mono or Consolas (Qt font substitutions).
- The sidebar numbers the pages 01 to 14 under TRADE / ANALYZE / SYSTEM, without icons.
